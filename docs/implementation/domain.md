# `domain` 实施骨架

## 目标

冻结共享模型与共享错误，为其他 crate 提供稳定依赖面。

## 前置依赖

- 无

## 输入与输出

- 输入：设计基线、旧系统概念映射
- 输出：稳定模型、错误类型、序列化测试

## 本轮范围

- 明确 `NewsItem`、`RssItem`、`RunContext`
- 明确错误分类骨架
- 增加序列化与反序列化测试

## 当前进展

- 共享错误已覆盖 `InvalidConfig` 与 `Storage`
- 其余抓取、解析、输出错误仍按后续模块实现节奏补充

## 暂不处理

- 复杂兼容层
- 所有旧字段一次性迁入

## 建议子任务

- 模型字段冻结
- 错误类型分层
- 序列化测试补齐

## 完成定义

- 对应契约文档已补齐
- 其他 crate 可基于该模型继续开发
- 结构变化有测试覆盖

## 验证命令

```bash
cargo test -p trendradar-domain
```
