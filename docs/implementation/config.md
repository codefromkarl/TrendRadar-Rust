# `config` 实施骨架

## 目标

收敛最小配置结构、默认值和校验规则。

## 前置依赖

- `domain` 错误边界稳定

## 输入与输出

- 输入：配置契约、最小配置 fixture
- 输出：可加载、可校验、可报错的配置模块

## 本轮范围

- 扩展 `AppConfig`
- 增加默认值
- 增加解析与校验用例

## 暂不处理

- 全量旧配置兼容
- 多格式配置解析

## 建议子任务

- 顶层配置结构拆分
- 校验规则与错误消息
- 合法 / 非法 fixture

## 完成定义

- 最小配置可加载
- 关键字段缺失可定位报错
- fixture 驱动测试通过

## 验证命令

```bash
cargo test -p trendradar-config
```
