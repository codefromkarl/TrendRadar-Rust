# `report` 实施骨架

## 目标

先实现结构化 JSON 输出，再为后续报告层预留边界。

## 前置依赖

- `domain` 模型稳定
- 输出契约稳定

## 输入与输出

- 输入：统一内容模型与运行元数据
- 输出：稳定 JSON 结果

## 本轮范围

- JSON 顶层结构
- 元数据字段
- 快照测试

## 暂不处理

- 完整 HTML 报告
- 复杂展示层样式

## 建议子任务

- JSON 契约
- 错误输出结构
- 快照测试

## 完成定义

- 固定输入输出稳定
- JSON 结构有快照或结构断言
- 与 `app` 编排解耦

## 验证命令

```bash
cargo test -p trendradar-report
```
