# Architecture

## 目标

Rust 版本采用“内核优先”的分层结构：

- 纯领域模型独立
- 纯逻辑模块尽量函数化
- 存储与抓取依赖领域模型，不反向侵入业务
- `app` 只做编排和入口

## Crates

### `domain`

定义数据模型、共享错误、运行元数据。

### `config`

负责配置模型、默认值与加载入口。

### `schedule`

负责将时间线配置解析为执行决策。

### `analyze`

负责过滤、聚合、排序等纯计算逻辑。

### `storage`

负责持久化抽象与后续 SQLite 实现。

### `fetch`

负责热点源和 RSS 抓取。

### `report`

负责结构化输出与后续 HTML 输出。

### `app`

负责协调所有模块，并暴露 CLI。
