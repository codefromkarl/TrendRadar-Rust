# 开发记录

这个目录用于记录 TrendRadar Rust 项目的完整开发过程。

目标不是写流水账，而是沉淀下面几类信息：

- 当时为什么这样做
- 做了什么
- 遇到了什么问题
- 学到了什么
- 下一步应该做什么

## 使用建议

建议按“一个阶段 / 一次会话 / 一个里程碑”记录一篇文档。

文件名建议：

- `YYYY-MM-DD-主题.md`
- 例如：`2026-04-10-bootstrap-environment.md`

## 推荐记录范围

- 环境准备
- 架构设计
- crate 拆分
- 测试补齐
- 迁移某个模块
- 遇到的坑与修复思路
- 阶段性复盘

## 目录约定

- [TEMPLATE.md](./TEMPLATE.md)：通用记录模板
- `YYYY-MM-DD-*.md`：具体开发记录

## 写法原则

- 先写事实，再写判断
- 写清“为什么”，不要只写“做了什么”
- 决策要带上下文
- 问题要带现象、原因、处理方式
- 每篇最后都写“下一步”
